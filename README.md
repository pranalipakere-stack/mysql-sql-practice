# MySQL SQL Practice

## About This Repository

This repository contains my SQL learning journey and hands-on practice using **MySQL Workbench**. It includes SQL queries and examples that I practised while learning database management and data analysis concepts.

## Topics Covered

- Database and table creation
- SQL data types and constraints
- Primary Key, Foreign Key, UNIQUE, NOT NULL and CHECK
- INSERT, UPDATE, DELETE and ALTER
- SELECT, WHERE, DISTINCT and ORDER BY
- Filtering using IN, BETWEEN and LIKE
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY and HAVING
- Subqueries and nested queries
- INNER JOIN, LEFT JOIN, RIGHT JOIN and CROSS JOIN
- Self Join
- Date and string functions
- Stored Procedures (IN, OUT and INOUT)
- Views
- UNION and UNION ALL
- Window Functions (RANK, DENSE_RANK and ROW_NUMBER)
- Common Table Expressions (CTEs)

## Tools Used

- MySQL
- MySQL Workbench

## Purpose

The purpose of this repository is to strengthen my SQL skills through practical exercises and prepare for entry-level Data Analyst roles.

## Learning Outcome

Through this practice, I gained experience in writing SQL queries, managing relational databases, retrieving data, combining tables, and performing basic data analysis.
